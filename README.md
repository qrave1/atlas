# Atlas — личный AI-планировщик в Telegram

Atlas принимает текстовые и голосовые сообщения, предлагает план изменений и записывает задачи в локальную SQLite. Для новых и изменяемых задач сначала показывает черновик; запись начинается только после подтверждения.

У каждой задачи отдельно задаются крайний срок и, по желанию, время выполнения. Длительность указывать необязательно. Если задан только срок, Atlas напомнит о задаче в 11:00 этого дня, чтобы не дублировать утренний план в 10:00. Эпики содержат подзадачи и показывают прогресс. Все даты и расписание работают в часовом поясе `Europe/Moscow`.

Atlas отправляет напоминания с кнопками «Готово», «Отложить на 15 минут», «Отложить на час», «Перенести», «Застрял — разбить шаг». Для важных задач можно попросить повторять напоминания каждые 4 часа в течение дня; обычная задача напоминается один раз. Ежедневный план приходит в 10:00, обзор — в 22:00.
